📊 Google Analytics 4 (GA4)

Recomendamos o GA4 por ser gratuito, poderoso e não precisar de tabelas extras no seu banco. Você consegue ver visitas, de onde vieram, quais produtos foram mais vistos, e quantos chegaram ao checkout.

  1. Acesse analytics.google.com e crie uma conta/propriedade GA4
  2. Copie o ID de medição (formato G-XXXXXXXXXX)
  3. Substitua G-XXXXXXXXXX no <head> de todos os templates HTML (index, produto, checkout, obrigado)
  4. Opcional: adicione eventos customizados no checkout para rastrear conversões
<!-- Cole isso no <head> de index.html, produto.html, checkout.html -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){"{"}dataLayer.push(arguments){"}"}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>

🎯 Eventos de conversão recomendados

Cole esses trechos no JavaScript das páginas correspondentes para rastrear funil completo no GA4:

// No checkout.html — quando abrir o checkout:
gtag('event', 'begin_checkout', {"{"} currency: 'BRL', value: total {"}"});

// No obrigado.html — quando pedido for criado:
gtag('event', 'purchase', {"{"} transaction_id: numero, value: total, currency: 'BRL' {"}"});
